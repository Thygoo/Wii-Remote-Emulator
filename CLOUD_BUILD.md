# Cloud APK build (no Android Studio required)

This project includes `.github/workflows/build-apk.yml` for GitHub Actions.

## Build with a browser on a computer

1. Unzip this archive locally. Open the inner `WiiRemoteAndroidPrototype_CloudBuild` folder.
2. Sign into https://github.com and create a new repository (for example `wii-remote-hid-lab`). Make the repository **private** if you do not want the code public.
3. Click **Add file > Upload files** and drag the CONTENTS of the `WiiRemoteAndroidPrototype_CloudBuild` folder into the upload page. Do **not** upload the ZIP as-is. The `app/`, `.github/`, and the two `.gradle.kts` files should appear in their original locations at the repository ROOT.
4. Click **Commit changes**. If your branch is `main` or `master`, the workflow builds automatically. Alternatively choose **Actions > Build Android APK > Run workflow**.
5. When the workflow succeeds, open its run under Actions, then download the artifact `WiiRemoteHIDLab-v0.2-debug`.
6. Extract the downloaded artifact ZIP to get `app-debug.apk`, then open the APK on your Android phone and allow installation from that source when asked.

This uses the Android debug signing key generated by the cloud build, so a separate signing key is not needed. If you install a later build produced by a different runner, Android may require uninstalling the earlier debug APK first. Export or back up any app data before uninstalling.

## Limitations

- The project has NOT been compiled in this environment or tested on a Wii U. GitHub Actions will be the first real Gradle compilation test, and errors may need fixing.
- Successful APK compilation does NOT establish Wii U pairing compatibility. Android Bluetooth HID does not fully emulate the legacy Wii Remote pairing stack.
- Building from a phone browser is possible in principle, but uploading an entire directory hierarchy is much easier using a computer browser; neither route requires installing Android Studio.
- This archive does not contain the Gradle wrapper; the workflow installs Gradle 8.9 in the cloud.
